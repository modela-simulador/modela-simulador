Recuperador de Claves WiFi

Recupera las contraseñas de redes WiFi guardadas en tu computadora

Esta herramienta te muestra los comandos nativos de tu sistema operativo para ver las contraseñas WiFi que tu computadora ya tiene guardadas. No hackea ni descifra nada.

Ver todas las redes WiFi guardadas

1

Abre CMD o PowerShell como Administrador (clic derecho → Ejecutar como administrador)

2

Copia y pega este comando para ver la lista de todas las redes guardadas:

netsh wlan show profiles
3

Para ver la contraseña de una red específica, usa este comando reemplazando NOMBRE_RED:

netsh wlan show profile name="NOMBRE_RED" key=clear

La contraseña aparece en la línea "Contenido de la clave" o "Key Content"

Script para ver TODAS las claves de una vez

Copia este script completo en CMD (como Administrador):

for /f "tokens=2 delims=:" %a in ('netsh wlan show profiles ^| findstr "Perfil de todos los usuarios"') do @(echo Red: %~a & netsh wlan show profile name="%~a" key=clear | findstr "Contenido de la clave")
Nota: Si tu Windows está en inglés, usa este comando alternativo:
for /f "tokens=2 delims=:" %a in ('netsh wlan show profiles ^| findstr "All User Profile"') do @(echo Network: %~a & netsh wlan show profile name="%~a" key=clear | findstr "Key Content")

Script PowerShell (alternativa avanzada)

Abre PowerShell como Administrador y pega esto:

(netsh wlan show profiles) | Select-String "\:(.+)$" | ForEach-Object { $name = $_.Matches.Groups[1].Value.Trim() $result = netsh wlan show profile name="$name" key=clear $pass = ($result | Select-String "Contenido de la clave\W+\:(.+)$") if ($pass) { $pass = $pass.Matches.Groups[1].Value.Trim() } else { $pass = "(sin clave / red abierta)" } [PSCustomObject]@{ Red = $name Clave = $pass } } | Format-Table -AutoSize

Recuperar claves WiFi en macOS

1

Abre la Terminal (Aplicaciones → Utilidades → Terminal)

2

Para ver la contraseña de una red específica, usa:

security find-generic-password -wa "NOMBRE_RED"

Se te pedirá tu contraseña de usuario de macOS para autorizar

Ver todas las redes guardadas

networksetup -listpreferredwirelessnetworks en0

Script para ver todas las claves

Pega esto en Terminal (te pedirá la contraseña de admin por cada red):

networksetup -listpreferredwirelessnetworks en0 | tail -n +2 | while IFS= read -r network; do network=$(echo "$network" | xargs) pass=$(security find-generic-password -wa "$network" 2>/dev/null) if [ -z "$pass" ]; then pass="(no disponible)"; fi echo "Red: $network | Clave: $pass" done
Nota: En macOS Sonoma y versiones recientes, también puedes ver las claves WiFi desde Ajustes del Sistema → Wi-Fi → clic en (i) junto a la red → Contraseña.

Usando Acceso a Llaveros (método gráfico)

1

Abre Acceso a Llaveros (Keychain Access) desde Spotlight

2

En el buscador, escribe el nombre de tu red WiFi

3

Haz doble clic en la red encontrada

4

Marca la casilla "Mostrar contraseña" e ingresa tu clave de administrador

Recuperar claves WiFi en Linux

1

Abre una Terminal

2

Las contraseñas se guardan en archivos de NetworkManager. Para ver todas:

sudo grep -rH "psk=" /etc/NetworkManager/system-connections/

Ver redes guardadas

nmcli connection show

Ver contraseña de una red específica

nmcli -s -g 802-11-wireless-security.psk connection show "NOMBRE_RED"

Script para ver todas las claves

nmcli -t -f NAME,TYPE connection show | grep wireless | cut -d: -f1 | while IFS= read -r net; do pass=$(nmcli -s -g 802-11-wireless-security.psk connection show "$net" 2>/dev/null) if [ -z "$pass" ]; then pass="(sin clave)"; fi echo "Red: $net | Clave: $pass" done

Método alternativo (archivos directos)

Cada red tiene un archivo de configuración con la clave:

sudo cat /etc/NetworkManager/system-connections/"NOMBRE_RED.nmconnection"

Busca la línea psk= en la sección [wifi-security]

Nota: Si usas una distro con wpa_supplicant en lugar de NetworkManager:
sudo cat /etc/wpa_supplicant/wpa_supplicant.conf
